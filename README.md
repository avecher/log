# Хроника проекта «Здесь был Буратино»

Трансмедиа-проект, 8 эпизодов, 1996–2026. Сообщество «Исходники».

## Структура
- `_posts/` — записи хроники
- `_layouts/default.html` — шаблон страницы
- `style.css` — стили
- `index.html` — главная страница

## Как добавить запись
1. Создать файл в `_posts/` с именем `ГГГГ-ММ-ДД-название.md`
2. Добавить фронтматер: layout, title, date
3. Commit & Push
